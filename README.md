# interim

A lightweight WIP internal cheat for COD4x (v21.5)

## Features (wip)

- Aimbot
- ESP (Box, Skeleton, Name, Distance, Looking At You Alerts)
- Cvars (Show Enemies on Radar, No Smoke, No Jump Cooldown, Third Person)
